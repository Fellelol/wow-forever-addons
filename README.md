# WoW Forever Addons

Custom addons for WoW Forever (interface 16001). Each folder is a standalone addon.

| Addon | What it does | Command |
|---|---|---|
| [MageCoach](MageCoach) | Mage leveling helper: talent coach (default: Frost AoE build, all paths checked against the WoW Forever talent data), trainer list, AoE and mana tips per level, map pins, zone suggestions, rotation helper and DPS meter. | `/mc` |
| [LaptopControls](LaptopControls) | Trackpad helper: A/D turn out of combat and strafe in combat, plus trackpad-friendly camera presets. | `/lc` |

## Install

Copy the addon folder (for example `MageCoach`) into your game's `Interface/AddOns/` directory.
The folder name must stay the same as the `.toc` file name. Then restart the game or `/reload`.
